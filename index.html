Advanced API Protection & API Shield

SecureFlow is a self-hosted API Shield designed to manage multiple API endpoints with dynamic rate limiting, JWT authentication, and real-time monitoring.

pip install secureflow-api-rate-LIMITER

Installation Guide

To get started with the SecureFlow Rate Limiter, install the package via pip:

pip install secureflow-api-rate-LIMITER

Once installed, initialize the service with interactive setup follow the documentation

Key Features

API Shield & Dynamic Limits

Deploy a robust API shield for your infrastructure. Configure limits at startup or override them per API key via the Admin API without restarting.

JWT Authentication

Secure registration, login, and token refresh cycles to protect your management endpoints.

Multiple API Management

Efficiently manage multiple API instances and developer tiers from a single centralized platform.

Real-time Monitoring

Monitor your API shield performance with a WebSocket-powered dashboard to track traffic and blocked requests live.

Complete Project Workflow

Follow these steps to integrate the rate limiter into your application logic.

  1. User Onboarding: Register via /auth/register and login via /auth/login to receive a JWT. 
    curl -X POST /auth/login -d '{"email":"user@example.com", "password":"..."}'
  2. API Key Creation: Use the JWT to generate a unique API key (rk_live_...). 
    curl -X POST /auth/create_api_key -H "Authorization: Bearer [JWT_TOKEN]"
  3. SDK Pre-Check: Before making a request, have your client check availability via /sdk/check.
  4. Execution & Tracking: Call your protected endpoints and report telemetry back via /sdk/track to keep analytics accurate.
  5. Monitoring: Use the Admin Dashboard at /admin/dashboard to view live traffic and logs.
